為什麼 TimesFM 在金融資料上失敗？

失敗原因分析

1. 信噪比極低：日頻股票報酬的 noise 遠大於 signal，預訓練時學到的 pattern（天氣、銷售等有規律的序列）不適用
2. 非平穩性：金融報酬的分佈隨時間劇烈變化（regime change），TimesFM 假設資料分佈穩定
3. 單變量限制：股價受無數外部因子驅動，單靠歷史價格序列預測本質上是弱信號
4. 預訓練偏差：100B 時間點的預訓練語料以能源、天氣、零售等「有模式」的序列為主

後續值得測試

1. 波動率聚類序列：GARCH 殘差 或 realized vol 可能有更強的自相關
2. 分鐘頻/tick 頻：高頻資料 mean-reversion 更明確，可能更適合 TSFM
3. 成交量序列：成交量有日內/週內週期性，符合 TSFM 預訓練分佈
4. Fine-tune：在台股資料上繼續訓練，測 marginal improvement

貳、VibeVoice ASR 實測 — 假開源的教訓

實測過程

# Step 1: 模型確認存在 HuggingFace ID: microsoft/VibeVoice-ASR Downloads: 585,324 Pipeline: automatic-speech-recognition Files: config.json + 8x model.safetensors (~14GB total) Architecture: VibeVoiceForASRTraining (7B, based on Qwen2 3584-hidden) # Step 2: 嘗試載入 transformers==5.6.0.dev0 (from GitHub main) AutoModel.from_pretrained("microsoft/VibeVoice-ASR") ERROR: model type `vibevoice` not recognized by Transformers # Step 3: 檢查是否有 custom modeling code Repo files: config.json, model-*.safetensors, README.md, figures/ NO modeling_vibevoice.py found NO tokenizer files found # Step 4: 檢查替代來源 microsoft/VibeVoice → 401 Repository Not Found (private/gated) vibevoice-community/* → 401 Repository Not Found
結論：VibeVoice ASR 目前無法使用。
• 權重公開在 HuggingFace（14GB），但缺少 modeling code（模型定義的 Python 類）
• transformers 官方尚未 merge vibevoice model type
• Microsoft 主 repo 需要認證存取，社群 fork 也不存在
• 這是「看起來開源但實際上無法使用」的典型案例
建議：等 transformers 正式支援 vibevoice 後再評估。或等 Microsoft 開放主 repo 的程式碼。

AI-Scientist-v2 架構值得借鏡的部分

雖然無法在本機執行，但 repo 結構和設計模式對我們有參考價值：

  • 漸進式樹搜索：自動分支假說 → 實驗 → 評估 → 修剪。這個模式可套用到量化策略搜索（假說=因子組合，實驗=回測）
  • 每篇約 $25 API 成本：意味著自動化研究的邊際成本已經很低
  • experiment manager agent：專門管理實驗分支的 agent 設計，可參考用於策略管理系統
本週的實測告訴我們：「開源」不等於「可用」。7 個熱門專案中，只有 1 個（TimesFM）真正能在本機跑出結果。其餘要嘛假開源、要嘛硬體門檻過高、要嘛缺少關鍵組件。研究報告必須以實際可執行為準。

肆、結論與下一步

本週實證結論

①時間序列基礎模型在金融預測上的「零樣本通用性」不存在。TimesFM 2.5 在台股 5 檔標的上，報酬 R² 全部為負、方向準確率低於 50%、波動率預測輸給 EWMA(20)。Google 在通用基準上的 SOTA 成績完全無法遷移到金融場景。
②本週 7 個「熱門開源」專案中，只有 1 個能真正跑通。「開源」在 2026 年已經成為 marketing 用語。權重公開 ≠ 可用。需要實際 pip install + model.forward() 才算數。
③簡單模型仍然是最強的 baseline。EWMA(20) 完勝 231M 參數的 TimesFM。均值預測完勝所有 ML 模型。在金融領域，「什麼都不做」往往是最好的策略。
